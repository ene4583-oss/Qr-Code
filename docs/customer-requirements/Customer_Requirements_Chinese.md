# 库存管理网站——客户需求确认表

Version 1.1 | 5 November 2026 | Customer decisions remain pending.

| 编号 | 使用者 | 功能 | 需求说明 | 确认方式／预期结果 | 建议优先级 | 客户意见状态 | 意见／修改要求 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| R01 | 工人 | 扫码进入商品 | 手机相机扫描标签，打开对应商品表单。 | 自动选中正确商品；无效编号不会悄悄切换为其他商品。 | 必要 | 待确认 |  |
| R02 | 工人 | 商品资料展示 | 显示商品编号、名称、可用图片与单位；不向工人显示库存数量。 | 工人能确认商品，但看不到库存余额。 | 必要 | 待确认 |  |
| R03 | 获准账号 | 领货验证表单 | 填写 Account、Password、数量并现场拍照；Upload face photo 直接开启独立 HTTPS 相机页，不提供 Purpose、角色选择或相册上传。 | 账号必须有 Stock out 权限；缺凭据、照片或数量非正数时拒绝；无文件／相册选项。 | 必要 | 待确认 |  |
| R04 | 系统 | 库存自动计算 | 领货扣库存；通过工头授权的进货加库存。 | 库存 10，领货 1 后为 9，再进货 1 后为 10；库存不足时拒绝领货。 | 必要 | 待确认 |  |
| R05 | 获准账号 | 进货权限与简单拍照 | 输入 Account、Password 并具有 Stock in 权限；独立 HTTPS 相机页直接启动镜头，只保留拍照与前后镜头图标，可拍员工或操作人。 | 没有 Stock in 权限不能进货；检查凭据、相机来源和新鲜度；实际手机相机权限仍须验证。 | 必要 | 待确认 |  |
| R06 | 系统 | 避免重复扣货 | 同一提交的网络重试不能重复计算。 | 重试已记录请求，仅产生一次有效库存变化。 | 必要 | 待确认 |  |
| R07 | 管理员 | 库存及记录查看 | 查看库存、单位和交易，包含员工／工头、时间、照片及编号旁的商品小图。 | 通过约 42 像素小图辨认商品；可核对交易，具有 Drive 权限时查看现场照片。 | 必要 | 待确认 |  |
| R08 | 管理员 | 新增及修改商品 | 维护编号、名称、类别、单位、期初库存、警戒值和图片。 | 新商品进入工人清单；编号唯一且固定；已有交易后不能改变单位。 | 必要 | 待确认 |  |
| R09 | 管理员 | 删除及恢复商品 | 停止使用商品但保留历史，需要时可恢复。 | 已删除商品不能提交新操作；恢复后保留原编号和记录。 | 必要 | 待确认 |  |
| R10 | 管理员 | 上传商品照片 | 选择商品并上传或更换展示照片。 | 刷新后表单及重新生成的标签显示新图片；与交易现场照片分开。 | 必要 | 待确认 |  |
| R11 | 管理员 | 更正错误交易 | 填写原因删除／作废交易，重新计算库存，保留原记录核查。 | 删除领货只加回一次；删除进货若导致负库存则拒绝。 | 必要 | 待确认 |  |
| R12 | 管理员 | 补货警戒值 | 为每件商品设定独立警戒值，并可标记已订货。 | 库存低于或等于警戒值时提示，已订货时不重复催单；补货高于警戒值会清除订货标记。 | 必要 | 待确认 |  |
| R13 | 管理员 | 补货通知 | 管理页面打开时提示低库存；可选邮件提醒。 | 打开的页面约每 30 秒检查；已配置邮件时，库存从警戒值上方降至警戒值或以下会尝试发送。 | 可选 | 待确认 |  |
| R14 | 管理员 | 选择及打印标签 | 勾选单件、多件或全部，查看已选清单并移除误选。 | 仅打印已选商品，包含编号、名称、单位、二维码、可用照片与可选标签文字。 | 必要 | 待确认 |  |
| R15 | 管理员 | 公司名称与 Logo | 修改公司名称，上传、更换或移除 Logo。 | 网站及新生成标签显示已保存的标识；其他设备刷新后更新。 | 可选 | 待确认 |  |
| R16 | 管理员／系统 | 按操作权限显示 Staff Status | 独立页面只显示 Account、Status、Action。新增、修改、删除账号，可选 Stock in、Stock out 或两种；每次更改重输管理员密码。 | 移除 Type 栏，Status 显示已授予操作；后台限制权限，保留旧权限、密码及历史。密码无位数要求并支持显示／隐藏。 | 必要 | 待确认 |  |
